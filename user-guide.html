ELMS User Guide

Import

Import a product, review the listing details, select the correct eBay account, and publish when ready.

Messages

The Messages inbox reads cached eBay conversations. Use Refresh when you want an immediate eBay sync; new-message webhooks can update the cache automatically when configured.

Orders

Orders are synchronized in the background. Use Refresh from eBay for an immediate manual sync.

eBay connection

Connect each seller account separately and make sure the required permissions are granted.
