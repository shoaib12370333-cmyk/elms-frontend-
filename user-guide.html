User Guide

Everything you need to go from an Amazon, AliExpress or CJdropshipping link to a live eBay listing, and to run your stores day to day.

1Getting started

ELMS turns an Amazon product link into an eBay listing and then helps you keep it running: stock, price, orders and buyer messages live in one place.

  1. Connect your eBay store. Open Settings → Connect an eBay account and approve the permissions on eBay.
  2. Set your selling defaults. In Settings → Selling settings press Fetch from eBay, then choose your payment, fulfillment and return policies and your item location.
  3. Import a product. Paste an Amazon link on the Import page (or use the browser extension).
  4. Review the draft and publish. Open the draft, check title, price, images and item specifics, then publish.
Publishing needs a payment policy, a fulfillment policy, a return policy and an item location. If one is missing ELMS tells you which.

2Working with more than one store

You can connect several eBay stores (for example a US and a UK store). The store selected in the sidebar decides what every page shows.

  • Drafts, Live listings, Orders, Messages, notifications, Import history and the Dashboard only show the selected store.
  • Switching store does not delete anything. The other store's data is kept and comes back when you switch back.
  • The same Amazon product can be drafted separately in each store.
  • Stores show their marketplace tag, e.g. [UK] or [US]. Give each store a clear name in Settings.
Disconnecting a store deletes its data from ELMS (drafts, live listings, orders, messages, notifications and import history). Listings that are already live on eBay are not touched. This cannot be undone.

3Importing products

Paste an Amazon product link on the Import page and choose a markup percentage. ELMS fetches the title, images, price, description and specifications and saves a draft in the selected store.

  • Bulk import: switch to the bulk tab and paste one link per line.
  • Browser extension: copy your extension key from Settings, then import straight from an Amazon page.
  • Import history lists everything you fetched for the selected store.

With Use dynamic policies on, the store's default policies are used. Turn it off to pick different policies for just this product. A country + postal code saved on the product overrides the store's item location.

5Item location and postal codes

eBay needs a complete postal code for the item location. For the UK that means the full code, for example SW1A 1AA, not just SW1A.

  1. In Settings → Selling settings choose Product location → Custom.
  2. Pick the country, type a city and press Generate valid code.
  3. ELMS finds a real postal code for that city and saves it as your inventory location.
If you type only the first part of a UK postcode, ELMS completes it to a real full postcode when it can, and shows a clear error when it cannot.

Hong Kong has no postal codes, so none is needed there.

6Publishing and live listings

Press Publish on a draft, or schedule it. Publishing runs in the background and you get a notification when it succeeds or fails.

The Live listings page shows stock, price, profit, views, watchers and item IDs. Click the Amazon or eBay link to open the source or the live eBay listing. Use Sync from eBay to refresh views and watchers, and the edit button to change a live listing in the full editor.

Views and watchers come from eBay. If eBay does not return a number for an item, ELMS leaves it blank instead of guessing.

7Orders and fulfillment

Orders from the selected store are synced automatically and grouped like Seller Hub: awaiting payment, awaiting shipment, shipped, delivered and cancelled.

  • Sync from eBay reads recent changes. Full sync (90 days) re-reads everything from the last 90 days. Run a full sync once after connecting a store.
  • Open an order to see payment, shipping address, tracking and notes.
  • Add the Amazon order number and the tracking number; ELMS sends the tracking to eBay so the order is marked shipped.

8Security and devices

Open Settings → Security to see where your account is signed in and what happened recently.

  • Devices signed in: browser, system, approximate place and last activity. Press Log out to end one device, Log out other devices to keep only this one, or Log out everywhere if you think someone else has your account.
  • New-device alerts: when your account signs in from a device it has not used before you get a notification in ELMS and, if you keep the switch on, an email.
  • Login activity: your recent sign-ins and failed password attempts (kept for 180 days). Places are approximate and come from the IP address.
If you see a sign-in you do not recognise: press Log out everywhere, then change your password.

9Messages

Buyer conversations for the selected store appear in one inbox. Filter by unread, needs reply, archived or trash, reply through eBay, add private notes that only you can see, and save reusable replies. Use Sync for an immediate refresh; new messages can also arrive automatically.

11Troubleshooting

"Invalid inventory location" or "full inventory location" on publish

The postal code is incomplete. Open Settings → Selling settings, choose a custom location and press Generate valid code, or enter the full postcode. Then publish again.

I can't see my other store's listings

Every page shows the store selected in the sidebar. Switch the store there.

Orders are missing

Make sure the right store is selected, then use Orders → Full sync (90 days). Reconnect the store in Settings if eBay reports the connection has expired.

Views or watchers are empty

eBay only returns them for some items. Press Sync from eBay on Live listings and try again later.

Publish failed

Check the notification for eBay's exact reason (missing category, policy, item specific or image). Fix the draft and publish again; the credit is refunded automatically.

Still stuck? Open Support in the sidebar and send a ticket.
